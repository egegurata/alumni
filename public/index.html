Alumni Tracking & Career Network

A full-stack MVC web application with RESTful JSON endpoints, relational PostgreSQL persistence, automated SQL migrations, and interactive OpenAPI documentation.

👥 Alumni Directory

Manage alumni and student profiles (`isAlumni`, `graduationYear`), inspect their published job postings, and execute full CRUD operations.

Open Users Directory

📢 Announcements

Publish and manage university bulletins, career fairs, and homecoming events across academic and alumni categories.

Manage Announcements

💼 Job Postings (1:N)

Explore career and internship opportunities posted by alumni (`users.id -> job_postings.user_id`) and apply directly.

Browse Job Board

📝 Applications (M:N)

Track candidate applications across job postings through the relational join table with composite uniqueness enforcement (`409 Conflict`).

View Applications

⚡ Swagger UI

Inspect and test every REST API endpoint (`/api/users`, `/api/announcements`, `/api/jobs`, `/api/applications`) directly in the browser.

Launch Swagger UI
